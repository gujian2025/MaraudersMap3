## 简介

这是一款哈利波特风格的上海科技大学地图。用户能够在地图上面标记节点与路线，并通过点击节点与路线进入论坛，在论坛中交流自己在这一区域的生活。

## 功能特性

- 个人模式：在地图上标记节点或路径，之后点击进入节点备忘录，在其中通过文字、照片、视频等方式记录自己在这一区域的生活
- 多人交互：在地图上标记节点或路径，之后点击进入节点论坛。在其中可以发表评论或帖子，进行讨论交流
- AR现实：可以通过手机摄像头，看到现实中的魔法生物3D建模的图像，通过按照特定路线滑动屏幕的方式触发摄像头中看到的魔法生物进行运动。

## 描述
- 封面：封面从下到上分为四层——背景星空层、羊皮纸层、文字层以及小工具层。背景星空为整体背景，羊皮纸层为整个地图功能的背景，文字层为封面的致谢文字，小工具层是诸如羽毛笔、墨水瓶等图标。通过在封面上上滑可以触发进入地图层功能。当上滑触发被检测到时，羊皮纸层与星空层不发生变化，但是羊皮纸的上的文字淡去，小工具图标开始缓慢在特定区域中漂浮，羊皮纸层上浮现出地图框。
- 地图：当进入地图层之后，地图的初始界面为学校平面地图的全局图。用户可以双指放大地图，双指放大时，星空背景不发生改变，地图随着羊皮纸一同放大，地图放大的过程中，一些细节建筑标识逐渐显现。小工具在地图周围缓慢漂浮。通过点击墨水瓶小工具，可以在地图上点击标记节点；通过点击羽毛笔小工具，可以在地图上通过点击点来标出路径；
- 交互：通过点击标记后的节点与路径，星空层保持不变，羽毛笔与墨水瓶漂浮出屏幕画面，出现羊皮纸被烧毁的动画，从星空中通过zoom的动画效果出现一本书，翻开至一页，上面即为可以进行交互与记录的平台。
- 返回：通过点击悬浮在上方的魔杖，出现动画，羊皮纸从屏幕上方展开，直到完全遮住书本，页面返回到地图页面，墨水瓶与羽毛笔从两边重新漂浮回屏幕。
